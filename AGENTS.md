# AGENT Instructions for XmlSchemaClassGenerator Repository

This repository contains multiple C# projects organized in the `XmlSchemaClassGenerator.sln` solution.

## Build and Test
- Build everything using `dotnet build XmlSchemaClassGenerator.sln`.
- Run the full test suite with `dotnet test` from the repository root.

## Coding Conventions
- Indent with **4 spaces** and avoid tabs.
- Use file-scoped namespaces (e.g. `namespace Foo;`).
- Place opening braces on a new line.

## Contributing
- For any non-trivial change, open an issue first.
- Blend new code with the existing style.
- Add or update unit tests when applicable.

Each subproject contains its own `AGENTS.md` with project specific notes.
