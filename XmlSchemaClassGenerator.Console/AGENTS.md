# AGENT Instructions: Console Application

This directory contains the command line tool implementation.

## Build
Run `dotnet build` in this folder or build the solution from the repository root. The executable is built for **net6.0** or later as specified in the project file.

## Code Style
- Follow the repository style: 4‑space indentation, file‑scoped namespaces, braces on new lines.

## Usage
The program entry point is `Program.cs`. It parses command line options using `Mono.Options`.
