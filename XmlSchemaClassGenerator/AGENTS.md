# AGENT Instructions: XmlSchemaClassGenerator Library

This project is the core library that converts XML Schema files to C# classes.

## Build
Run `dotnet build` in this directory or build the solution from the repository root.

## Code Style
- C# files use 4‑space indentation and file‑scoped namespaces.
- Opening braces go on a new line.
- Target frameworks are **netstandard2.0** and **net462**.

## Notes
The public API is consumed by the console application and the CLI tools. Keep backward compatibility when possible.
